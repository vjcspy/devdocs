### Phase 3: Detailed Implementation Steps

1. **Define VN30 symbols & models**
   - Thêm constant `VN30_SYMBOLS` trong `vn30_index_calculator.py` với 30 mã VN30.
   - Tạo `VN30IndexCandle` model (pydantic) theo schema đã mô tả.

2. **Implement VN30IndexCalculator.__init__**
   - Lưu `start_date`, `end_date`, `interval`.
   - Validate `interval == IntradayInterval.FIVE_MINUTES`:
     - Nếu khác, raise `ValueError("VN30IndexCalculator only supports FIVE_MINUTES interval")`.

3. **Load Stock & total_shares**
   - Cho mỗi symbol trong `VN30_SYMBOLS`:
     - Tạo `StockDataCollector(symbol, start_date, end_date, interval)`.
     - Gọi `stock()` để lấy `Stock`.
     - Check `stock.total_shares`:
       - Nếu `None` hoặc `<= 0` → raise `ValueError` với message rõ ràng.
     - Lưu vào map `stocks[symbol] = stock`.

4. **Load 5m price candles**
   - Với từng collector:
     - Gọi `price_candles_by_date()` để lấy `dict[date, list[PriceCandle]]`.
     - Nếu không có dữ liệu trong range → raise `ValueError`.
   - Build `price_map[symbol]: dict[str, int]`:
     - Key: `candle.time` (ISO 8601).
     - Value: `candle.close` (giá đại diện cho slot).
   - Lưu danh sách `sorted_times[symbol]` = sort key của `price_map[symbol]`.

5. **Build 5m timeline chung**
   - Chọn 1 mã VN30 (ví dụ `"VCB"`) để lấy `exchange` đại diện.
     - Hoặc đảm bảo `exchange` là HOSE nếu cần.
   - Gọi `get_intraday_timepoints(exchange, int(IntradayInterval.FIVE_MINUTES))` để lấy list HH:MM.
   - Với mỗi ngày trong `[start_date, end_date]`:
     - Build `date_midnight_epoch` từ `YYYY-MM-DDT00:00:00Z` giống logic trong `tick_candles_by_date`.
     - Với từng HH:MM:
       - Tính epoch slot, convert sang ISO 8601 UTC bằng `pendulum.from_timestamp(..., tz="UTC").to_iso8601_string()`.
       - Append vào `timeline`.
   - Đảm bảo `timeline` sort tăng dần theo thời gian.

6. **Align giá từng symbol lên timeline (forward-fill)**
   - Cho mỗi symbol:
     - Khởi tạo `last_price = None` và chỉ số `idx` cho `sorted_times[symbol]`.
   - Duyệt `timeline` theo thứ tự:
     - Với mỗi `t`:
       - Cho từng symbol:
         - Di chuyển `idx` qua tất cả `sorted_times[symbol]` <= `t`, cập nhật `last_price`.
         - Nếu `last_price` là `None` tại `t` → raise `ValueError` (missing data for symbol at time t).
       - Lưu `price_at_time[symbol][t] = last_price`.

7. **Tính total market cap và base**
   - Khởi tạo `total_cap_by_time: dict[str, float] = {}`.
   - Với từng `t` trong `timeline`:
     - `total_cap_t = 0.0`.
     - Với từng symbol:
       - Lấy `price = price_at_time[symbol][t]`.
       - Lấy `shares = stocks[symbol].total_shares`.
       - `total_cap_t += price * shares`.
     - Nếu `total_cap_t <= 0` → raise `ValueError`.
     - Lưu `total_cap_by_time[t] = total_cap_t`.
   - Xác định `t0` = time đầu tiên trong `timeline` với `total_cap_by_time[t0] > 0`.
   - `base_cap = total_cap_by_time[t0]`.
   - Base index = `1000.0`.

8. **Tính VN30 index và build output**
   - Duyệt `timeline`:
     - `cap = total_cap_by_time[t]`.
     - `idx_value = 1000.0 * cap / base_cap`.
     - Tạo `VN30IndexCandle` với:
       - `time = t`
       - `open = idx_value`
       - `close = idx_value`
       - `high = idx_value`
       - `low = idx_value`
       - `value = cap` (tùy chọn, có thể để `None` nếu không muốn expose vốn hóa).
   - Return `list[VN30IndexCandle]` sort theo `time`.

9. **Error handling & logging**
   - Dùng logger có sẵn (tương tự `StockDataCollector`) để log:
     - Số lượng symbol, khoảng ngày, số lượng slot.
     - Lý do fail khi raise error (missing data, total_cap = 0, interval không hợp lệ, ...).
